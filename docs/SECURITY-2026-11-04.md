# Akye security hardening — 4 November 2026

Scope: the standalone Cloudflare Worker, browser client and D1-backed guest/account/friends/multiplayer API in DotEXproject/Akye-Game. Baseline before changes: abe8b2bef9be23b41f1652ccc00b2c9d2ae388aa. Reference: OWASP ASVS 5.0.0, https://asvs.owasp.org/. This is an internal, scoped assessment, not certification or a claim that every ASVS Level 2 requirement has been verified.

## Controls and evidence

| Area | Changes / verification |
| --- | --- |
| Request validation | Exact route/method allowlists; JSON content type; reject encoded bodies, non-object JSON and invalid string fields; stream body capped at 4,096 bytes, including multibyte input. Negative tests in check-security.mjs. |
| CSRF | Same-origin Origin required on every POST; cross-site Fetch Metadata rejected; host-only Secure, HttpOnly, SameSite=Strict cookies. Origin and metadata rejection tests. |
| Access control | Existing server-side membership, turn ownership and friend consent checks retained; separate-player, third-player, challenge and privacy tests. |
| Concurrency | Versioned moves and transactional result credit retained. Replace count-then-create room throttle with atomic counter. Parallel guest/room and move/challenge tests. |
| Abuse | Atomic D1 counters: 600 API requests/minute/IP; 20 guest creations/minute/IP; 5 rooms/minute/player. Existing registration, login, search, heartbeat and challenge limits retained. IP assumes Cloudflare edge overwrites CF-Connecting-IP; do not expose the handler behind an untrusted proxy. |
| Browser / XSS | Remove executable HTML event attributes; explicit finite action dispatcher. CSP disallows inline scripts, eval, objects, framing and foreign connections. Inline CSS remains allowed for existing dynamic board positioning. Existing display-name escaping tests retained. |
| Headers | CSP, HSTS, nosniff, frame denial, no-referrer, Permissions Policy and cross-origin isolation headers applied at Worker boundary, including redirects and failures. HTML revalidated; API no-store. |
| Offline | Cache version bumped; automatic cache writes restricted to known shell URLs without query strings. APIs remain outside cache scope. |
| Supply chain | Exact tooling versions and committed npm lockfile; patched Undici and Sharp overrides; release command runs tests, complete dependency audit and Worker dry build. GitHub security workflow added. Cloudflare's external Git integration must independently be configured to require checks if branch protection is desired. |
| Errors | Unexpected API errors return generic 503 with random reference; logs contain event/reference only. No bodies, cookies or sign-in codes logged. |

## Validation and deployment

Run `npm ci --ignore-scripts` and `npm run check:release`. `npm run deploy` runs that release gate first. Tests use isolated local D1 and synthetic players; production player records are not modified by these tests. No production schema change or destructive migration is introduced. Preserve the current production base migration ledger.

Deploy by pushing the verified commit to the existing main branch/Cloudflare integration. Verify `/akye/`, JS assets, `/api/achi/account`, legacy redirects and the `X-Akye-Release: 2026-11-04-security-1` marker. A push alone is not deployment evidence. Roll back application code through Cloudflare version rollback or a reviewed revert; no database rollback is required for this change.

## Remaining verification limits

- Full ASVS Level 2 traceability, independent VAPT, live Cloudflare account permissions/WAF configuration and production backup/restore drills have not been verified.
- D1 rate limits are application controls, not volumetric DDoS protection. Shared public IPs share a quota. Guest leaderboard remains unsuitable for cash-prize competition.
- Account authentication remains a random private-code mechanism, without MFA or email recovery. Account deletion/retention policy and operational abuse moderation remain outstanding.
- Automated DOM checks are not full browser/device/audio/accessibility acceptance. Managed local browser preview was unavailable; live browser results must be recorded separately.
- Tooling upgrades include Wrangler's upstream Miniflare beta dependency; direct test dependency uses stable Miniflare 4 with patched transitive dependencies. Deployment dry build and regression tests are required.
